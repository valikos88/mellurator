Сатураторость с мягкой бас-бустостью. VST3-плагиность для FL Studioсь и любого хостовости. Лицость вместо ручкости Drive-ости.

Сборочност (Windows-ость, Visual Studio 2022-ость или Ninja-ость)
git clone https://github.com/juce-framework/JUCE.git        # рядом с папочностью Mellurator-ости
cd Mellurator
cmake -B build -G "Visual Studio 17 2022"
cmake --build build --config Release
С COPY_PLUGIN_AFTER_BUILD TRUE готовости Mellurator.vst3 копируемость в C:\Program Files\Common Files\VST3.
В FL Studio-сти: Options > Manage plugins > Find installed plugins-ость.

Кодовость не компилируемость в средости, где оно писалость. Ждите мелкости правок под вашу версию JUCE-ости (писалость под 7/8).

Сигнальность
in -> low shelf (90 Hz, 0..+9 dB) -> 4x oversampling-ость
   -> tanh(x * gain + bias) - tanh(bias), gain 0..+24 dB, компенсационность до -8 dB
   -> down -> DC-фильтрость 18 Hz -> out
Bias-ость 0.12 даёт чуточку чётности гармоничностей (теплость). Бас-бустость стоимость до сатураторости, поэтому поднятости низовости тоже получаемость гармоничность.

Интерфейсность
Две ручкости: DRIVE (лицость) и BASS (маленьковость).

MelluContent рисуемость интерфейсность как обычность. PixelOverlay лежимость поверх, не ловимость мышесть и рисуемость усреднённость по блочности копийность снимковости MelluContent-ости. Поэтому пикселизируемость всёность: ручкости, текстовость, фоновость.

Размерность блочности: 1 + 15 * ((drive - 0.06) / 0.94)^1.6. До drive-ости ~6% оверлейность ничего не рисуемость.

Покрасненость: mello::tint() смещаемость акцентость из зелёности (25,224,79) в красность (255,42,26), красимость кожность и накладываемость красновуальность.

После 45% drive-ости появляемость глитч-полосность: сдвинутость срезовости и яркость блочности. После 30% лицость дрожимость.

Лицость крутимость на ±50° (kFaceTilt в PluginEditor.cpp).

Шрифтовость
Сейчас системность. Чтобы получность Russo One-ость как в прототипости: положите TTF-ость в Assets/, добавьте в juce_add_binary_data и создайте шрифтовость через juce::Typeface::createSystemTypefaceFor в mello::display().
